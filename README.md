## 🎯 Quick Start in 3 Minutes

### Step 1: Get Your OpenAI API Key (1 minute)

1. Go to https://platform.openai.com/api-keys
2. Click **"Create new secret key"**
3. Copy the key (starts with `sk-...`)

**First time?** OpenAI gives you $5 in free credits! = **833 minutes of dictation FREE!**

### Step 2: Configure the App (30 seconds)

1. Launch the app
2. Paste your API key in the 🔑 **OpenAI API Key** section
3. Click **"Save API Key"**
4. Select your microphone from the dropdown

**Done!** Your settings are saved automatically! 🎉

### Step 3: Start Dictating! (1 minute to master)

#### 🎯 **Push-to-Talk Mode (Default)**

1. Open Notepad (or Word, Gmail, any app!)
2. Click where you want text
3. **HOLD** `Ctrl+Shift` (or your chosen hotkey)
4. Speak: *"Bonjour comma je vais bien point"*
5. **RELEASE** the hotkey
6. Watch the magic! ✨ → `Bonjour, je vais bien.`

#### 🔴 **Live Mode (Hands-Free)**

1. Select **"Live Mode"** in the Recording Mode section
2. Click **"START LIVE MODE"**
3. Just **speak naturally** - no need to hold any key!
4. Watch the status:
   - 🟢 **Green** = Silent (no cost)
   - 🔴 **Red** = You're speaking (API active)

## 🛠️ Troubleshooting

### ❓ "Processing" shows but no text appears

**Debug Mode is Active!** Check your console (CMD window) for messages:

```
DEBUG: Whisper returned: 'your text here'
DEBUG: After clean_filler_words: 'your text here'
DEBUG: About to type: 'your text here'
DEBUG: Successfully pasted text using Ctrl+V
```

**Common causes:**
1. ❌ **Notepad not in focus**: Click in Notepad before releasing hotkey
2. ❌ **Text too short**: System filters single characters
3. ❌ **Hallucination filtered**: Whisper sometimes returns "merci", "thank you" (filtered automatically)

**Solutions:**
- ✅ Make sure cursor is blinking in target app
- ✅ Speak at least 2-3 words
- ✅ Check console for debug messages
- ✅ Try Push-to-Talk mode first (simpler than Live Mode)

### ❓ Microphone not working

1. ✅ Check microphone is plugged in
2. ✅ Refresh devices using 🔄 button
3. ✅ Test with Windows Voice Recorder
4. ✅ Select correct device from dropdown

### ❓ API errors

- **"Invalid API key"**: Check your key starts with `sk-`
- **"Insufficient credits"**: Add credits at https://platform.openai.com/account/billing
- **"Network error"**: Check internet connection

### ❓ French punctuation not working

- ✅ Ensure **language is set to "Français"**
- ✅ French rules apply automatically
- ✅ You'll see non-breaking spaces before `;` `:` `?` `!`

## 💡 Pro Tips & Best Practices

### 🎯 **Get 99% Accuracy**

1. **Speak clearly but naturally** - No need to enunciate excessively
2. **Use good microphone** - Even a $20 USB mic works wonders
3. **Quiet environment** - Background noise affects quality
4. **Short segments** - 10-30 seconds per recording = faster + more accurate
5. **Add context** - Use Transcription Quality Prompt for specialized terms

### 💰 **Minimize Costs**

1. **Use Live Mode** - Only transcribes when you speak (see 🟢/🔴 indicator)
2. **Pause between thoughts** - Prevents transcribing "euh", "umm"
3. **Speak continuously** - One 30-second recording vs 10x 3-second = same cost, better accuracy
4. **Monitor status** - Red = costing, Green = free!

### ⚡ **Maximize Productivity**

1. **Learn verbal punctuation** - "deux points" faster than typing `:`
2. **Set up custom words** - Add your common terms once, use forever
3. **Use hotkey you can hold comfortably** - Default `Ctrl+Shift` works great
4. **Keep app open** - Minimal resource usage, always ready
